# Criar Rota 1.0.0

Entrega de consolidação em 19/10/2026. A numeração 1.0.0 foi escolhida pelo
responsável pelo produto; substitui o identificador histórico 2.0.0 do pacote.

## Base e integração

- Base: `c761e43431ef1bdad719297142fbe036bd583725` de `main`, que consolida
  expedição, roteirização e interfaces da referência publicada `1a5701b`.
- Mantidos o motor consolidado, APIs, controles de acesso e regras comerciais
  dessa base. O painel comercial experimental de outro checkout não foi aplicado
  sobre as funcionalidades atuais.
- A revisão comparou os arquivos locais de conta, mobile, erros, splitter e
  monitores grandes com a consolidação: essas melhorias já estavam incorporadas.
- Não utiliza o antigo pacote de substituição de CSS/JavaScript no startCommand.
  Esta entrega é compilada da fonte versionada, com o Dockerfile do repositório.

## Correções incluídas

- Barra inferior preservada ao girar celulares, inclusive telas de toque de
  até 1024px com altura de até 600px. O conteúdo reserva espaço para a navegação.
- Contêineres de cada item deixam de ocupar uma tela inteira na barra móvel.
  Rolagem horizontal contida, primeiro/último item acessíveis e sem balão repetido.
- Removido o gesto global que recarregava a aplicação ao puxar 160px. Desativada
  a ação de atualização por overscroll vertical, mantendo rolagem e zoom.
- Impressão móvel abre documento visível durante o clique; oferece botão
  Imprimir / Salvar PDF e orientação quando o navegador bloqueia a nova aba.
  O desktop mantém a impressão isolada existente.
- Versão 1.0.0 no pacote, menu da conta e `/api/version`.
- Mantidas as melhorias de temas, modais, mapas, botões, painel redimensionável,
  telas de erro e dimensões para monitores grandes da base consolidada.

## Validação

- `npm run test:all`: 121 testes, zero falhas e zero ignorados na consolidação.
- `npm run test:ui`: 24 cenários de navegação/recolhimento/toque/rotação e teste
  de impressão com chamadas nativas simuladas.
- `npm run typecheck` e build de produção.
- `npm run test:release-ui`: aplicação compilada com sessão, rota e OSRM
  sintéticos, sem alterar dados de produção. Passou: rota preservada após puxar
  e girar, limites da barra, etiquetas, menu com versão e clique real em Imprimir
  abrindo documento com número de pedido. A chamada à impressão nativa é simulada.
- Impressora física, AirPrint/Android spooler e gestos em aparelho físico ainda
  exigem aceite do usuário. Emulação não comprova esses comportamentos nativos.

## Publicação e retorno

1. Compilar e testar a fonte desta versão; registrar commit e tag `v1.0.0`.
2. Verificar o banco com consulta somente leitura. Em 19/10 todas as migrações
   até `0015_workbook_versions.sql` já constavam no ledger da produção.
3. Usar `sh -c "node scripts/check-schema.mjs && exec node server.js"` como
   startCommand no Railway. O shell explícito é necessário para executar ambos
   os comandos no container. A entrega não executa migrations nem seeds.
4. Subir a fonte com `railway up --detach` no serviço Criar Rota/production.
   Aguardar SUCCESS e verificar `/api/version`, página inicial, recursos e sessão.
5. Se houver regressão, retornar ao deploy anterior
   `5ee49dbc-de58-4c4f-af26-fc62e83a02b1` e à configuração de inicialização
   correspondente. Preservar variáveis, volumes e banco.

O deploy não deve apagar dados de aplicativo, fila IndexedDB ou comprovantes.
Backup local de configuração é operacional e não deve entrar no Git.

## Reproduzir testes de navegador

Disponibilizar Playwright e navegador Edge (ou definir PLAYWRIGHT_CHANNEL).
Quando a biblioteca estiver fora do projeto, definir PLAYWRIGHT_MODULE_PATH
para o módulo instalado. Executar `npm run test:ui`.
