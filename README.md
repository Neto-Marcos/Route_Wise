# RouteWise

Planejador de rotas responsivo recuperado a partir da versão publicada no Railway.

## Executar localmente

Sirva esta pasta com qualquer servidor HTTP estático. Para produção, o `Dockerfile` usa Nginx e funciona diretamente no Railway.

## Serviços externos

- OpenStreetMap/Nominatim para pesquisa de endereços.
- OSRM para cálculo e desenho de rotas.

Uso sujeito às políticas e limites públicos desses serviços.
